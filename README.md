# Project 1 — Responsive Multi-Page Website
## Jaamacadda Al-Azhar (Al-Azhar University) Website

A responsive, multi-page educational website built using pure HTML5 and CSS3 for Al-Azhar University. This project strictly follows mobile-first responsive design principles, accessibility guidelines, and semantic HTML structure.

---

## 📌 Project Requirements Checklist & Features

- **4+ Linked Pages:**
  - `index.html` (Home Page)
  - `about.html` (About Us Page)
  - `courses.html` (Faculties Page)
  - `contact.html` (Contact Page)
  - All pages share a consistent layout, header, navigation, and footer.

- **Fully Responsive (320px → 1920px):**
  - Designed using a **Mobile-First** approach.
  - Seamlessly adjusts from small smartphone viewports (320px) up to large desktop monitors (1920px).

- **CSS Layout Techniques:**
  - **Flexbox:** Used for the responsive navigation menu, header, and content alignment.
  - **CSS Grid:** Used for the card grid layout across pages for desktop viewports.

- **Clean & Accessible Code:**
  - **0 Validation Errors:** W3C HTML5 and CSS3 validated.
  - **0 JavaScript / Frameworks:** Built purely with semantic HTML5 and CSS3.
  - Accessible markup with semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) and proper `alt` tags for images.

- **Functional Contact Form:**
  - Includes input validation (`required`, proper `type` attributes for emails and text).

- **Deployment:**
  - Deployed and live via **GitHub Pages**.
